# Wireframe V1 — Student / Team Leader

ยืนยัน User Flow ใหม่เรียบร้อย: **ผู้ใช้สามารถสร้างทีมก่อนหรือสร้างโครงงานก่อนก็ได้** โดยไม่บังคับลำดับ และคงขอบเขต Prototype V1 เดิมทั้งหมด

ต่อไปนี้เป็นข้อกำหนด Wireframe สำหรับนำไปจัดวางใน Figma ครบ 9 หน้าจอ โดยใช้ Desktop Frame ขนาด 1440 × 900 px และสไตล์ Modern Academic
