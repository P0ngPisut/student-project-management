# ข้อความเริ่มต้นสำหรับส่งให้ Codex ใน VS Code

> สำหรับทีมรับงานSubmission/Milestoneปัจจุบัน อ่าน [Team Start Here](../team/START_HERE.md) ก่อน ข้อความread-onlyauditด้านล่างเป็นpromptประวัติ ไม่ใช่คำสั่งใหม่ที่แทนขอบเขตเจ้าของอนุมัติให้ทีมพัฒนาแล้ว

> ประวัติ prompt เริ่มต้น: audit นี้ดำเนินการแล้ว สำหรับสถานะล่าสุดอ่าน [Reference](../database/SCHEMA_V1_REFERENCE.md) และ [Backlog](../progress/BACKLOG.md) ก่อน ขอบเขตคำสั่งผู้ใช้ล่าสุดมีผลเหนือคำสั่งเริ่มต้นด้านล่าง ไม่ถือว่าเอกสารนี้อนุมัติการแก้ไข/ติดตั้ง DB เพิ่มเติม

โปรดอ่านเอกสาร `docs/codex_project_handoff/PROJECT_HANDOFF_CODEX.md` และไฟล์ต้นฉบับทั้ง 5 ไฟล์ใน `docs/codex_project_handoff/sources/` ให้ครบก่อน

งานนี้คือ **รับช่วงบริบทและตรวจสอบความคืบหน้าของ Student Project Management System** ได้แก่ Frontend, Backend, Database, UX/UI และแผนพัฒนา 4 สัปดาห์

สิ่งที่ต้องทำตอนนี้เท่านั้น:
1. ตรวจดู Repository ปัจจุบันแบบ **read-only** รวมถึง Git status, โครงสร้างไฟล์, scripts, API routes, design/docs และไฟล์ DB schema ที่มีจริง
2. เปรียบเทียบกับข้อมูลใน PROJECT_HANDOFF_CODEX.md โดยแยกสถานะ **ยืนยันจากโค้ด / เป็นเพียงแผนหรือ Wireframe / ยังไม่พบหลักฐาน / ยังต้องตัดสินใจ**
3. จัดทำรายงานสรุปสถานะปัจจุบันและรายการความต่าง พร้อม path ของไฟล์ที่อ้างถึง
4. เสนอขั้นตอนพัฒนาถัดไป **เพียงขั้นตอนเดียว** พร้อมบอกไฟล์ที่จำเป็นต้องแก้ แล้วรอคำสั่งจากฉัน

ข้อห้าม: **อย่าเพิ่งแก้ไข สร้าง ลบ ย้ายไฟล์, อย่าเปลี่ยน UX/UI, อย่าเพิ่ม Endpoint, อย่ารัน migration/SQL ที่แก้ข้อมูล, และอย่าตัดสินใจแทนฉันเมื่อ Requirement ยังไม่ชัด** รวมทั้งห้ามเผยแพร่ secrets จาก `.env`

สำคัญ: เอกสารส่งต่อเป็น snapshot ของการสนทนาก่อนหน้า ไม่ใช่หลักฐานว่าสภาพ Git repository ณ ตอนนี้เหมือนเดิม จึงต้องยืนยันจากไฟล์จริงก่อนทุกครั้ง
