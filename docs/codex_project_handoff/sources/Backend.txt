## ขั้นตอนถัดไป — ทดสอบการเชื่อมต่อผ่าน FastAPI

ปัจจุบัน `database.py` เชื่อมต่อฐานข้อมูลได้แล้ว แต่ยังไม่ได้ทดสอบผ่าน FastAPI

ก่อนดำเนินการขั้นตอนนี้ **ขออนุญาตแก้ไขไฟล์ `backend/main.py`** เพื่อเพิ่ม Endpoint สำหรับตรวจสอบการเชื่อมต่อฐานข้อมูล โดยคง Endpoint เดิมไว้ทั้งหมด
