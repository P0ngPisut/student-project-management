# Progress Report — Template

ใช้หลังงานแต่ละรอบ บันทึกตามหลักฐานจริง ไม่คัดลอกผล PASS เก่ามาเป็นผลรอบใหม่

## ขอบเขตรอบนี้

- วันที่/เวลา: `<ระบุ timezone>`
- งานที่อนุมัติ / Task IDs: `<อ้าง BACKLOG.md>`
- Branch / HEAD: `<ผลตรวจจริง>`
- Working tree: `<tracked changes / untracked; HEAD อย่างเดียวไม่ระบุเวอร์ชันไฟล์ที่ยังไม่ commit>`
- ไฟล์ที่เปลี่ยนและเหตุผล: `<รายการ>`
- ข้อจำกัด: `<DB ที่อนุญาต, transaction policy, สิ่งที่ไม่ได้ตรวจ>`

## สถานะงาน

| Task / Requirement | สถานะก่อน → หลัง | หลักฐานโค้ด/เอกสาร | การเชื่อมต่อ | Test / วันที่ / version | Blocker / งานถัดไป |
|---|---|---|---|---|---|
| `<Pxx / กฎ V1>` | `<Done/In Progress/Not Started/Blocked>` | `<path/function/section>` | `<ไม่เชื่อม / DB-only / API→DB / FE→API→DB>` | `<PASS/FAIL/Not Verified พร้อมขอบเขต>` | `<สิ่งที่ยังขาด>` |

Not Verified เป็นระดับหลักฐาน ไม่ใช่ค่าที่แปลงเป็น Done ได้จากชื่อไฟล์ บันทึกผลก่อนหน้าแยกจากผลที่รันใหม่

## ผลตรวจและทดสอบ

| รายการ/คำสั่ง | ทำในรอบนี้หรือผลเดิม | ขอบเขต/สภาพแวดล้อม | ผล | หลักฐาน/ข้อจำกัด |
|---|---|---|---|---|
| `<คำสั่งที่ไม่มี secrets>` | `<รอบนี้/วันที่เดิม>` | `<offline / test DB / actor role>` | `<PASS/FAIL/Not Run/Not Verified>` | `<exit code, จำนวนกรณี, log ที่ปกปิด secrets>` |

ถ้ามี DB writes: ระบุชื่อ DB ที่ตรวจยืนยัน, effective role, transaction/ROLLBACK หรือข้อยกเว้น COMMIT ที่อนุมัติ, ผลตรวจคืน baseline และหมายเหตุว่า sequence อาจเพิ่ม ห้ามใส่รหัสผ่านหรือ URL เชื่อมต่อ
